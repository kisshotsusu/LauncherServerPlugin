API 参考（客户端 / 启动器对接清单）

状态　GET /api/status
版本索引　GET /api/versions
更新描述　GET /api/version/<id>
完整性清单　GET /api/manifest.json?platform=Windows
云端文件浏览　GET /api/files?platform=Windows&path=CodeBuild/Content
云端文件下载　GET /files/packages/<平台>/<相对路径>
更新包下载　GET /files/versions/<版本>/<文件名>
重建索引　POST /api/versions/reindex
重新生成清单　POST /api/manifest/generate?platform=Windows
上传文件　POST /api/upload?target=package|version&platform=Windows&path=&versionId=（multipart，字段名 file）
一键导入　POST /api/import/hotpatcher
开放版本（查询/设置）　GET/POST /api/enabled_versions　{platform, versions:[...]}
删除版本　DELETE /api/version/<id>（移入 data/trash 回收站）
重启服务器　POST /api/server/restart
存储测试　POST /api/storage/test　{storage:{...}}
启动器历史版本　GET /api/launcher/versions／POST {version, dir}／DELETE /api/launcher/versions/<版本>
启动器版本发布　POST /api/launcher/publish　{version, note}
背景资源　GET /api/launcher/background　POST /api/launcher/background/dir　POST /api/launcher/background
所有接口均带当前项目前缀（如 /codebuild/api/...）；配置 admin_token 后管理操作需携带 Authorization: Bearer <token>。

访问格式管理（服务器级）

定义各项目的访问地址格式与保留前缀。修改立即生效（监听端口/根重定向之外的部分需重启）。
访问前缀格式：每个项目通过其标识获得独立地址，例如标识 cc 的访问地址为 /cc/。

详情

新建项目

仅限字母、数字、下划线。创建后访问地址为 /<标识>/
新建项目将复制该项目的设置，并拥有独立的项目空间（数据目录隔离）。

重命名项目空间

仅限字母、数字、下划线，且不能与保留前缀（api/web/files）或其它项目冲突。默认项目的标识改名后其数据目录仍在服务器根（不迁移）。
