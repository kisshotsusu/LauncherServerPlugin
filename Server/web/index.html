选择服务器上的背景图文件夹（PNG 序列帧，按文件名排序），客户端启动自检自动下载新版背景。当前版本：- · -
状态　GET /api/status
版本索引　GET /api/versions
更新描述　GET /api/version/<id>
完整性清单　GET /api/manifest.json?platform=Windows
云端文件浏览　GET /api/files?platform=Windows&path=CodeBuild/Content
云端文件下载　GET /files/packages/<平台>/<相对路径>
更新包下载　GET /files/versions/<版本>/<文件名>
重建索引　POST /api/versions/reindex
重新生成清单　POST /api/manifest/generate?platform=Windows
上传文件　POST /api/upload?target=package|version&platform=Windows&path=&versionId=（multipart，字段名 file）
一键导入　POST /api/import/hotpatcher
开放版本（查询）　GET /api/enabled_versions
开放版本（设置）　POST /api/enabled_versions　{platform, versions:[...]}，客户端仅可见列表内版本
删除版本　DELETE /api/version/<id>（移入 data/trash 回收站）
重启服务器　POST /api/server/restart
启动器历史版本　GET /api/launcher/versions／POST {version, dir}／DELETE /api/launcher/versions/<版本>
启动器版本发布　POST /api/launcher/publish　{version, note}（从版本文件夹快照 exe）
背景资源清单　GET /api/launcher/background（客户端自检用，指定文件夹）
背景目录设置　POST /api/launcher/background/dir　{dir}
背景 FPS / 清除配置　POST /api/launcher/background　{frameFps}／POST /api/launcher/background/clear
配置了 admin_token 时，管理操作需携带 Authorization: Bearer <token>。
